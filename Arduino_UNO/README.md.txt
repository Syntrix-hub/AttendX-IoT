# Arduino UNO Firmware

This firmware controls the Smart RFID Attendance System.

## Features

- RFID Authentication
- Student Database
- LCD Display
- Green LED
- Red LED
- Buzzer
- Login
- Logout
- Serial Communication with NodeMCU

## Required Libraries

- SPI
- MFRC522
- Wire
- LiquidCrystal_I2C

## Board

Arduino UNO
